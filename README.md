## 📖 Overview

Get Keja is a modern web-based rental management platform built to simplify property discovery, listing management, and communication between landlords and tenants.

The platform provides separate dashboards for landlords and tenants, enabling landlords to manage their rental properties while helping tenants search, compare, and save properties that match their preferences.

The project was developed as a full-stack application using React, TypeScript, PHP APIs, Node.js, and MySQL.

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/developerrono/get-keja.git
```

```bash
cd get-keja
```

---

## Install Dependencies

```bash
npm install
```

---

## Start the Frontend

```bash
npm run dev
```

---

## Backend Setup

1. Install XAMPP
2. Start Apache
3. Start MySQL
4. Create the project database
5. Import the SQL file
6. Copy the PHP backend into the XAMPP `htdocs` directory

Example:

```
C:\xampp\htdocs\get-keja-backend
```

---

## Database Configuration

Update the database connection file with your credentials.

```php
Host: localhost
Database: getkeja
Username: root
Password:
```
