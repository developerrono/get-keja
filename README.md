# Get Keja

Get Keja is a full-stack house rental web application developed to simplify the process of finding, listing, and managing rental properties in Kenya.

## Features

- User Authentication
- Landlord Dashboard
- Tenant Dashboard
- Property Listings
- Property Details
- Property Comparison
- Favorites
- Google Maps Integration
- Image Upload
- Property Search
- Property Filtering
- Real-time Property Availability

## Technologies Used

Frontend

- React
- TypeScript
- TanStack Router
- React Query
- Tailwind CSS
- Shadcn UI

Backend

- Node.js
- Express.js
- PHP APIs
- MySQL
- XAMPP

Tools

- Git
- GitHub
- VS Code

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/get-keja.git
```

Install dependencies

```bash
npm install
```

Run the frontend

```bash
npm run dev
```

Start the backend

- Start Apache
- Start MySQL
- Import the SQL database
- Place PHP APIs inside the XAMPP htdocs folder
